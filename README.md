### ⚡ Özellikler

- ⏱️ **Zaman Ayarlı Komutlar:** OwO cooldown sürelerine uygun otomatik komut gönderimi (`owo pray`, `owo hunt`, `owo battle` vb.).
- 🔄 **Döngü Yönetimi:** Belirlenen aralıklarla kesintisiz ve kararlı arka plan çalışması.
- 🛡️ **Hata Yakalama:** Bağlantı kopmaları ve sunucu gecikmelerine karşı otomatik yeniden bağlanma desteği.

---

### 🚀 Kurulum & Çalıştırma

Projeyi yerel ortamında çalıştırmak için:

```bash
# 1. Repoyu klonla
git clone [https://github.com/furqyz/dc-owootobot.git](https://github.com/furqyz/dc-owootobot.git)

# 2. Proje dizinine git
cd dc-owootobot

# 3. Bağımlılıkları yükle
npm install

# 4. Projeyi başlat
node index.js
